# 🎓 Student Grade Calculator

A simple web application that calculates a student's total marks, average, grade, and pass/fail status using **HTML**, **CSS**, and **JavaScript**.

## 📌 Features

* Enter marks for multiple subjects
* Calculates the total score automatically
* Calculates the average mark
* Assigns a letter grade based on the average
* Displays Pass or Fail status
* Validates user input
* Saves entered data using Local Storage
* Light/Dark theme toggle
* Responsive design for desktop and mobile

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📂 Project Structure

```text
student-grade-calculator/

```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it in your web browser.
4. Enter the student's marks.
5. Click the **Calculate** button to view the results.
